Pertemuan 5: Percabangan (switch-case)

Sejauh ini program yang kamu buat selalu berjalan lurus dari atas ke bawah. Sekarang saatnya program bisa memilih tindakan berdasarkan input pengguna memakai switch-case. Baca ringkasannya di bawah, lalu uji pemahamanmu lewat kuis di bagian akhir.

switch-case case & break default int & char

Tujuan Pembelajaran

Capaian Pembelajaran (Elemen Algoritma dan Pemrograman — Fase F): peserta didik mampu mengembangkan program terstruktur dengan strategi algoritmik yang tepat, menuliskannya menjadi kode program sesuai kaidah bahasa pemrograman yang dipakai, serta mengelola data dalam program menggunakan struktur yang sesuai dengan kebutuhan persoalan.

Tujuan Pembelajaran pertemuan ini: melalui pengamatan dan praktik menulis program C++ sederhana, peserta didik mampu (1) menjelaskan konsep percabangan serta perbedaan if-else dan switch-case, (2) menuliskan struktur switch-case lengkap dengan case, break, dan default, (3) menerapkan switch-case pada data bertipe int dan char, (4) menjelaskan akibat break yang dihilangkan (fall-through), serta (5) menggabungkan cin dan switch-case dalam program yang dapat dikompilasi tanpa galat.

01 · Konsep Dasar

Mengenal Percabangan

Semua program yang sudah kamu buat sebelumnya mengeksekusi barisnya satu per satu, dari atas ke bawah, tanpa memilih jalan. Percabangan memungkinkan program mengambil tindakan yang berbeda tergantung kondisi atau pilihan yang diberikan.

🔀 if-else

if-else

Cocok untuk kondisi berupa rentang nilai, misalnya "kalau nilai ≥ 80" atau "kalau angka lebih dari 0".

🎛️ switch-case

switch-case

Cocok untuk memilih di antara beberapa nilai tetap yang sudah pasti, misalnya pilihan menu 1, 2, 3, atau 4.

Perbandinganif-elseswitch-case
Yang diperiksaKondisi benar atau salah, termasuk rentang nilaiKecocokan sebuah nilai dengan daftar case
Contoh kasusNilai ≥ 75 dinyatakan lulusAngka 1–7 menjadi nama hari
Tipe dataBebas, termasuk string dan desimalHanya int atau char

Pertemuan ini fokus ke switch-case, karena bentuknya paling pas untuk program dengan menu pilihan.

02 · Sintaks

Struktur dan Cara Kerja switch-case

Begini bentuk umum sebuah switch-case di C++:

struktur-switch.cpp🔒 ketik sendiri
switch(pilihan) {
case nilai1:
// aksi kalau pilihan == nilai1
break;
case nilai2:
// aksi kalau pilihan == nilai2
break;
default:
// aksi kalau tidak ada case yang cocok
}
BagianFungsi
switch(pilihan)Variabel yang nilainya mau dicocokkan, biasanya sudah diisi lewat cin sebelum masuk ke switch
case nilai:Blok yang dijalankan kalau isi pilihan cocok dengan nilai tersebut
break;Menghentikan switch supaya tidak lanjut memeriksa case di bawahnya
default:Blok cadangan yang dijalankan kalau tidak ada case yang cocok
!

Jangan lupa break

Kalau break; dihilangkan, program akan terus "jatuh" (fall-through) mengeksekusi case di bawahnya walaupun nilainya sudah tidak cocok lagi. Ini kesalahan yang paling sering terjadi pada pemula.

03 · Contoh Berjalan

Contoh Program: Penentu Nama Hari

Program ini meminta angka 1–7 lalu menampilkan nama harinya.

penentu-hari.cpp🔒 ketik sendiri
#include <iostream>
using namespace std;
int main() {
int hari;
cout << "PENENTU NAMA HARI" << endl;
cout << "==================" << endl;
cout << "Masukkan Angka (1-7): ";
cin >> hari;
switch(hari) {
case 1:
cout << "Hari = Senin" << endl;
break;
case 2:
cout << "Hari = Selasa" << endl;
break;
case 3:
cout << "Hari = Rabu" << endl;
break;
case 4:
cout << "Hari = Kamis" << endl;
break;
case 5:
cout << "Hari = Jumat" << endl;
break;
case 6:
cout << "Hari = Sabtu" << endl;
break;
case 7:
cout << "Hari = Minggu" << endl;
break;
default:
cout << "Angka tidak valid" << endl;
}
return 0;
}

04 · Contoh Tambahan

switch dengan Tipe char

switch-case tidak hanya bisa mencocokkan angka (int) — karakter tunggal (char) juga bisa. Contoh berikut meminta satu huruf nilai (A–E), lalu menampilkan predikatnya.

?

Kenapa tidak langsung pakai string?

switch-case di C++ hanya menerima nilai bertipe bilangan bulat (int) atau karakter tunggal (char). Teks yang lebih dari satu huruf (string) tidak bisa dipakai langsung di dalam switch(...). Kalau ingin bercabang berdasarkan teks, biasanya dipakai if-else dengan operator == untuk membandingkan string.

predikat-nilai.cpp🔒 ketik sendiri
#include <iostream>
using namespace std;
int main() {
char nilai;
cout << "PENENTU PREDIKAT NILAI" << endl;
cout << "======================" << endl;
cout << "Masukkan Nilai (A-E): ";
cin >> nilai;
switch(nilai) {
case 'A':
cout << "Predikat = Sangat Baik" << endl;
break;
case 'B':
cout << "Predikat = Baik" << endl;
break;
case 'C':
cout << "Predikat = Cukup" << endl;
break;
case 'D':
cout << "Predikat = Kurang" << endl;
break;
case 'E':
cout << "Predikat = Sangat Kurang" << endl;
break;
default:
cout << "Nilai tidak dikenali" << endl;
}
return 0;
}

char nilai;

05 · Bekal Tambahan

Hal Penting Lainnya

Kesalahan kecil yang paling sering terjadi saat baru belajar switch-case.

⚠️ lupa break

Fall-through

Tanpa break;, program lanjut menjalankan case di bawahnya walau nilainya tidak cocok lagi.

⚠️ tipe data

Hanya int dan char

string dan bilangan desimal seperti double tidak bisa dipakai di switch(...).

⚠️ kutip

'A' vs "A"

Karakter memakai kutip satu, string memakai kutip dua. Di case untuk char, pakai kutip satu.

⚠️ huruf besar/kecil

'A' ≠ 'a'

Huruf besar dan kecil dianggap nilai yang berbeda, jadi input a tidak cocok dengan case 'A':.

Bonus: Menggabungkan Beberapa case

Kadang beberapa nilai punya tindakan yang sama. Dalam kasus ini, break sengaja tidak ditulis di antara case-case tersebut, sehingga semuanya "jatuh" ke blok yang sama. Contoh: angka 6 dan 7 sama-sama akhir pekan, angka 1–5 sama-sama hari kerja.

hari-kerja.cpp🔒 ketik sendiri
#include <iostream>
using namespace std;
int main() {
int hari;
cout << "Masukkan Angka Hari (1-7): ";
cin >> hari;
switch(hari) {
case 6:
case 7:
cout << "Akhir pekan" << endl;
break;
case 1:
case 2:
case 3:
case 4:
case 5:
cout << "Hari kerja" << endl;
break;
default:
cout << "Angka tidak valid" << endl;
}
return 0;
}
Simulasi jendela Console setelah ditekan F11
11–13
case 6:
case 7:
    cout << "Akhir pekan" << endl;

Case 6 tidak punya break, jadi kalau nilainya 6, program lanjut ke case 7 dan menjalankan baris yang sama. Di sini fall-through dipakai dengan sengaja.

06 · Praktik Gabungan

Contoh Program Gabungan

Sekarang kita gabungkan cin dan switch-case dalam satu program sederhana: kalkulator yang memilih operasi berdasarkan karakter operator (+, -, *, /).

kalkulator.cpp🔒 ketik sendiri
#include <iostream>
using namespace std;
int main() {
double a, b;
char op;
cout << "KALKULATOR SEDERHANA" << endl;
cout << "Masukkan (angka operator angka): ";
cin >> a >> op >> b;
switch(op) {
case '+':
cout << "Hasil = " << a + b << endl;
break;
case '-':
cout << "Hasil = " << a - b << endl;
break;
case '*':
cout << "Hasil = " << a * b << endl;
break;
case '/':
cout << "Hasil = " << a / b << endl;
break;
default:
cout << "Operator tidak valid" << endl;
}
return 0;
}
