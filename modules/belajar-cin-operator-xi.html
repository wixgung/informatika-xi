CIN dan Operator

Setelah belajar variabel dan tipe data, sekarang kita belajar cara membuat program yang bisa membaca input dari pengguna lewat cin, lalu mengolahnya dengan operator aritmatika, perbandingan, dan logika. Baca ringkasannya di bawah, lalu uji pemahamanmu lewat kuis di halaman berikutnya.

cin >> Operator Aritmatika Operator Perbandingan Operator Logika

Tujuan Pembelajaran

Capaian Pembelajaran (Elemen Algoritma dan Pemrograman — Fase F): peserta didik mampu mengembangkan program terstruktur dengan strategi algoritmik yang tepat, menuliskannya menjadi kode program sesuai kaidah bahasa pemrograman yang dipakai, serta mengelola data dalam program menggunakan struktur yang sesuai dengan kebutuhan persoalan.

Tujuan Pembelajaran pertemuan ini: melalui pengamatan dan praktik menulis program C++ sederhana, peserta didik mampu (1) menjelaskan fungsi cin untuk membaca input pengguna dan membedakannya dari cout, (2) mempraktikkan pembacaan satu maupun beberapa nilai sekaligus dengan cin >>, (3) menerapkan operator aritmatika, perbandingan, dan logika dalam program C++, serta (4) menggabungkan cin dan operator untuk menyelesaikan persoalan sederhana yang dapat dikompilasi tanpa galat.

01 · CIN Dasar

Membaca Satu Nilai dengan cin

cin dipakai untuk membaca nilai yang diketik pengguna lewat keyboard, lalu menyimpannya ke sebuah variabel — kebalikan dari cout yang menampilkan nilai ke layar.

📥 input

cin

Membaca nilai dari keyboard. Selalu dipasangkan dengan operator >> (arahnya ke variabel).

📤 output

cout

Menampilkan nilai ke layar. Dipasangkan dengan operator << (arahnya ke layar).

Cara gampang mengingat arah panahnya: cin >> variabel — nilai "masuk" ke variabel. cout << variabel — nilai "keluar" ke layar.

cin-satu-nilai.cpp🔒 ketik sendiri
#include <iostream>
using namespace std;
int main() {
int umur;
cout << "Masukkan umur kamu: ";
cin >> umur;
cout << "Umur kamu adalah " << umur << " tahun" << endl;
return 0;
}
Simulasi jendela Console setelah ditekan F11

Angka 17 di atas adalah yang diketik pengguna setelah program berhenti menunggu di baris cin >> umur;.

6
int umur;

Variabel umur dideklarasikan lebih dulu — masih kosong, siap diisi dari input pengguna.

8
cin >> umur;

Program berhenti sejenak menunggu pengguna mengetik angka lewat keyboard, lalu menyimpannya ke variabel umur.

✏️ Ketik program ini sendiri di Dev-C++, jalankan dengan F11, lalu coba ketik angka umurmu sendiri.
02 · CIN Lanjutan

Membaca Banyak Nilai Sekaligus

Kalau butuh beberapa nilai sekaligus, kita bisa merangkai >> berkali-kali dalam satu baris — tidak perlu satu cin untuk tiap variabel.

cin-banyak-nilai.cpp🔒 ketik sendiri
#include <iostream>
using namespace std;
int main() {
int hari, bulan, tahun;
cout << "Masukkan tanggal (hari bulan tahun): ";
cin >> hari >> bulan >> tahun;
cout << "Tanggal: " << hari << "/" << bulan << "/" << tahun << endl;
return 0;
}
Simulasi jendela Console setelah ditekan F11

Ketiga angka dipisah dengan spasi saat diketik, lalu masuk berurutan: nilai pertama ke hari, kedua ke bulan, ketiga ke tahun.

!

Hati-hati: cin >> berhenti di spasi

Untuk tipe string, cin >> hanya membaca sampai spasi pertama. Kalau pengguna mengetik Made Wirawan, variabel string hanya akan berisi Made saja — kata "Wirawan" tidak ikut terbaca. (Untuk membaca kalimat penuh, dipakai perintah lain yang akan dibahas di pertemuan selanjutnya.)

✏️ Ketik program ini sendiri, coba jalankan dengan mengetik tiga angka dipisah spasi.
03 · Operator

Operator Aritmatika

Operator aritmatika dipakai untuk menghitung nilai dari dua angka atau lebih.

OperatorArtiContohHasil
+Penjumlahan5 + 27
-Pengurangan5 - 23
*Perkalian5 * 210
/Pembagian5 / 22 (kalau keduanya int)
%Sisa bagi (modulus)5 % 21

Perhatikan baris /: kalau kedua variabelnya bertipe int, hasil pembagian dibulatkan ke bawah (bagian desimal dibuang). Supaya hasilnya tetap punya desimal (misal 17/5 = 3.4), minimal salah satu variabelnya harus bertipe double atau float.

operator-aritmatika.cpp🔒 ketik sendiri
#include <iostream>
using namespace std;
int main() {
int a, b;
cout << "Masukkan dua bilangan bulat: ";
cin >> a >> b;
cout << "Jumlah: " << a + b << endl;
cout << "Selisih: " << a - b << endl;
cout << "Kali: " << a * b << endl;
cout << "Bagi: " << a / b << endl;
cout << "Sisa Bagi: " << a % b << endl;
return 0;
}
Simulasi jendela Console setelah ditekan F11
✏️ Ketik program ini sendiri, coba dengan angka yang berbeda dan tebak hasilnya sebelum menjalankan F11.
04 · Operator

Operator Perbandingan & Logika

Operator perbandingan dan logika menghasilkan nilai bool — true (ditampilkan sebagai 1) atau false (ditampilkan sebagai 0).

Operator Perbandingan

OperatorArtiContohHasil
==Sama dengan5 == 51 (true)
!=Tidak sama dengan5 != 31 (true)
>Lebih besar5 > 31 (true)
<Lebih kecil5 < 30 (false)
>=Lebih besar sama dengan5 >= 51 (true)
<=Lebih kecil sama dengan5 <= 30 (false)

Jangan tertukar: = (satu sama dengan) dipakai untuk mengisi nilai, sedangkan == (dua sama dengan) dipakai untuk membandingkan.

Operator Logika

OperatorArtiBernilai true jika...
&&ANDkedua kondisi bernilai true
||ORminimal salah satu kondisi bernilai true
!NOTmembalik nilai: true jadi false, false jadi true
operator-perbandingan.cpp🔒 ketik sendiri
#include <iostream>
using namespace std;
int main() {
int nilai;
cout << "Masukkan nilai ujian: ";
cin >> nilai;
cout << "Lulus (>=75): " << (nilai >= 75) << endl;
cout << "Nilai sempurna (==100): " << (nilai == 100) << endl;
cout << "Rentang aman (>=75 dan <=100): " << (nilai >= 75 && nilai <= 100) << endl;
return 0;
}
Simulasi jendela Console setelah ditekan F11

Perhatikan hasilnya ditampilkan sebagai angka 1 atau 0, bukan tulisan "true"/"false" — ini kebiasaan bawaan cout untuk nilai bool.

✏️ Ketik program ini sendiri, coba masukkan nilai yang berbeda-beda dan tebak hasilnya dulu sebelum menjalankan F11.
05 · Bekal Tambahan

Hal Penting Lainnya

Kesalahan kecil yang paling sering terjadi saat baru belajar cin dan operator.

⚠️ cin berhenti di spasi

cin >> untuk string

Kalimat dengan spasi hanya terbaca sampai kata pertama. Solusinya (memakai getline) ada di bawah ini.

⚠️ = vs ==

Isi nilai vs bandingkan

= (satu) untuk mengisi nilai, == (dua) untuk membandingkan. Tertukar keduanya bisa membuat logika program salah total.

⚠️ pembagian int

Hasil bagi dibulatkan

Kalau kedua variabel bertipe int, bagian desimal hasil bagi dibuang. Pakai double/float kalau butuh desimalnya.

⚠️ tampilan bool

true/false tampil 1/0

Hasil operator perbandingan dan logika bertipe bool, ditampilkan cout sebagai angka 1 (true) atau 0 (false), bukan tulisan.

Bonus: Membaca Kalimat Penuh dengan getline

Supaya nama seperti "Made Wirawan" ikut terbaca lengkap dengan spasinya (bukan cuma "Made"), cin >> diganti dengan getline(cin, nama). Kalau sebelumnya sudah ada cin >> untuk membaca angka, tambahkan cin.ignore(); sebelum getline untuk membuang sisa Enter yang masih "nyangkut" di buffer.

getline-nama.cpp🔒 ketik sendiri
#include <iostream>
#include <string>
using namespace std;
int main() {
int umur;
string nama;
cout << "Umur: ";
cin >> umur;
cin.ignore(); // buang sisa Enter di buffer sebelum getline
cout << "Nama lengkap: ";
getline(cin, nama);
cout << "Halo, " << nama << endl;
return 0;
}
Simulasi jendela Console setelah ditekan F11
11
cin.ignore();

Setelah cin >> umur;, tombol Enter yang ditekan pengguna masih tersimpan di buffer. Kalau tidak dibuang, getline berikutnya akan langsung membaca baris kosong itu, bukan nama yang ingin diketik.

13
getline(cin, nama);

Berbeda dari cin >>, getline membaca satu baris penuh sampai Enter ditekan — spasi di tengah kalimat seperti pada "Made Wirawan" ikut terbaca semuanya.

cin.ignore() hanya perlu dipakai kalau sebelum getline ada cin >> lain. Kalau getline dipakai di awal program (belum ada cin >> sebelumnya), baris ini boleh dilewati.

06 · Praktik Gabungan

Contoh Program Gabungan

Sekarang kita gabungkan cin dan operator dalam satu program sederhana: menghitung total belanja dan status gratis ongkos kirim.

gabungan.cpp🔒 ketik sendiri
#include <iostream>
#include <string>
using namespace std;
int main() {
string namaPembeli;
int hargaSatuan, jumlahBeli;
cout << "Nama Pembeli: ";
cin >> namaPembeli;
cout << "Harga Satuan Barang: ";
cin >> hargaSatuan;
cout << "Jumlah Barang: ";
cin >> jumlahBeli;
int totalBelanja = hargaSatuan * jumlahBeli;
bool gratisOngkir = totalBelanja >= 100000;
cout << "Halo, " << namaPembeli << endl;
cout << "Total Belanja: " << totalBelanja << endl;
cout << "Gratis Ongkir: " << gratisOngkir << endl;
return 0;
}
Simulasi jendela Console setelah ditekan F11

Penjelasan Bagian Penting

10
cin >> namaPembeli;

Karena namaPembeli bertipe string, ingat: sebaiknya diketik satu kata saja (tanpa spasi) supaya seluruhnya ikut terbaca — sesuai catatan di Langkah 02 (atau pakai getline kalau namanya lebih dari satu kata, seperti di Langkah 05).

16
int totalBelanja = hargaSatuan * jumlahBeli;

Operator * mengalikan harga satuan dengan jumlah barang yang dibeli, hasilnya langsung disimpan ke variabel totalBelanja.

17
bool gratisOngkir = totalBelanja >= 100000;

Hasil operator perbandingan (yang bertipe bool) bisa langsung disimpan ke sebuah variabel, tidak harus langsung dipakai di cout. Di sini, pembeli dapat gratis ongkir kalau total belanjanya minimal Rp100.000.

✏️ Ketik program ini sendiri, jangan copy-paste — supaya terbiasa dengan penulisannya.
