01 · Pengenalan

Apa itu C++?

C++ adalah salah satu bahasa pemrograman — cara kita "berbicara" dengan komputer supaya komputer melakukan apa yang kita mau, lewat kode yang kita tulis.

C++ terkenal karena programnya bisa berjalan dengan sangat cepat. Karena itu, C++ banyak dipakai untuk membuat hal-hal yang butuh performa tinggi, misalnya game, aplikasi komputer, sampai sistem di dalam perangkat elektronik.

Istilah "bahasa pemrograman": sekumpulan aturan penulisan yang dipahami komputer, mirip seperti bahasa Indonesia atau Inggris, tapi khusus untuk memberi perintah ke komputer.

01

Cepat & Ringan

Program C++ diubah langsung menjadi bahasa yang dimengerti mesin, sehingga jalannya cepat.

02

Banyak Dipakai

Dipakai untuk membuat game, aplikasi desktop, sampai sistem operasi.

03

Bahasa Dasar

Cocok untuk belajar cara berpikir terstruktur sebelum lanjut ke bahasa lain.

02 · Sejarah

Sejarah Singkat C++

Kenapa namanya "C++"? Yuk lihat perjalanan singkatnya.

1979

Awal Mula

Seorang peneliti bernama Bjarne Stroustrup mulai mengembangkan versi baru dari bahasa C, dengan nama sementara "C with Classes".

1983

Nama "C++" Muncul

Namanya diganti menjadi C++. Simbol ++ dalam C++ artinya "tambah 1" — jadi namanya kurang lebih berarti "C, tapi satu langkah lebih maju".

1985

Dirilis ke Publik

C++ mulai bisa dipakai secara luas oleh para pembuat program di seluruh dunia.

1998 – sekarang

Terus Diperbarui

C++ terus mendapat pembaruan (versi baru) sampai sekarang, supaya makin mudah dipakai dan makin canggih.

04 · Alat yang Dipakai

Mengenal Dev-C++

Kita menulis dan menjalankan kode C++ memakai aplikasi bernama Dev-C++. Supaya kode bisa berjalan, kode harus melalui proses compile — yaitu proses komputer memeriksa dan menerjemahkan tulisan kodemu menjadi bahasa yang dimengerti mesin. Semua perintah untuk itu ada di menu Execute, seperti gambar di bawah ini:

1

Compile F9

Memeriksa tulisan kodemu dan menerjemahkannya ke bahasa mesin. Kalau ada kesalahan penulisan (disebut syntax error), pesannya akan muncul di panel Compiler di bagian bawah. Program belum dijalankan pada tahap ini.

2

Run F10

Menjalankan program yang sebelumnya sudah di-compile. Hasilnya (disebut output) akan muncul di jendela hitam yang disebut Console.

3

Compile & Run F11

Menggabungkan langkah 1 dan 2 sekaligus — kode diperiksa, diterjemahkan, lalu langsung dijalankan. Ini yang paling sering kamu pakai. Cukup tekan tombol F11 di keyboard!

4

Rebuild All F12

Meng-compile ulang semua file dari awal. Berguna kalau program terasa aneh setelah kamu melakukan banyak perubahan.

Langkah Praktis

  1. Buka Dev-C++, lalu buat file baru lewat File → New → Source File.
  2. Ketik kode C++ kamu di area editor.
  3. Simpan filenya dengan File → Save (atau Ctrl+S), beri nama berakhiran .cpp, misalnya latihan1.cpp.
  4. Tekan tombol F11 di keyboard untuk meng-compile sekaligus menjalankan programmu.
  5. Lihat hasilnya di jendela Console yang muncul.
05 · Fondasi

Struktur Dasar Program C++

Hampir semua program C++ punya "kerangka" yang mirip. Yuk kenali dulu bagian-bagiannya.

1

#include <iostream>

Baris ini menyertakan kumpulan perintah siap pakai (disebut library atau pustaka) untuk menampilkan tulisan ke layar dan nanti membaca input dari keyboard.

2

using namespace std;

Baris ini membuat kita bisa langsung menulis cout tanpa awalan tambahan. Tanpa baris ini, kita harus menulis std::cout setiap kali.

3

int main() { }

Ini disebut fungsi (kumpulan perintah yang diberi nama). Fungsi main wajib ada di setiap program C++ — di sinilah program mulai dijalankan.

4

Kurung kurawal { }

Tanda kurung ini menandai awal dan akhir dari sekumpulan perintah, disebut satu blok kode.

5

Titik koma ;

Setiap perintah (disebut statement) di C++ harus diakhiri titik koma — mirip tanda titik di akhir kalimat. Lupa menulis ; adalah penyebab error paling sering! Dalam istilah pemrograman, tanda ; ini disebut statement terminator (penanda akhir sebuah pernyataan).

6

return 0;

Baris terakhir sebelum penutup fungsi main, menandakan program selesai berjalan dengan baik, tanpa masalah.

Satu hal penting: C++ bersifat case-sensitive, artinya huruf besar dan huruf kecil dianggap berbeda. Menulis cout tidak sama dengan Cout atau COUT — komputer akan menganggapnya error.

06 · Praktik Pertama

Program "Hello, World!"

Ini adalah program pertama yang biasa ditulis siapa pun saat mulai belajar bahasa pemrograman baru — tujuannya sederhana: menampilkan tulisan ke layar.

Contoh 1a — helloworld.cpp🔒 ketik sendiri
#include <iostream>
using namespace std;
int main() {
cout << "Hello, World!" << endl;
return 0;
}
Contoh 1b — helloworld_std.cpp🔒 ketik sendiri
#include <iostream>
int main() {
std::cout << "Hello, World!" << std::endl;
return 0;
}

Kedua versi di atas menghasilkan output yang sama persis. Bedanya: Contoh 1a memakai using namespace std; lalu cukup menulis cout, sedangkan Contoh 1b tidak memakai baris itu sehingga harus menulis std::cout (dengan awalan std::) setiap kali. Tanda :: disebut scope resolution operator — cara menunjuk "ambil cout dari dalam std". Untuk latihan di kelas ini, kedua cara sama-sama boleh dipakai — pilih salah satu, jangan dicampur dalam satu program.

Tampilan di jendela Console setelah ditekan F11 (Contoh 1a maupun 1b)
Hello, World!
Process exited after 0.01 seconds with return value 0
Press any key to continue . . .
✏️ Coba ketik salah satu versi (1a atau 1b) di Dev-C++, lalu tekan F11.

Penjelasan Setiap Baris (Contoh 1a)

1
#include <iostream>

Menyertakan pustaka iostream, yang berisi perintah untuk menampilkan teks ke layar (cout) dan nanti membaca input dari keyboard (cin, akan dipelajari di pertemuan berikutnya).

3
using namespace std;

Perintah-perintah standar C++ seperti cout sebenarnya berada di dalam "wadah" bernama std. Baris ini membuat kita bisa langsung memakainya tanpa menulis std:: setiap kali (lihat perbandingannya dengan Contoh 1b di atas).

5
int main() {

Awal dari fungsi main, tempat program mulai berjalan. Kurung kurawal { membuka blok kode milik fungsi ini.

6
cout << "Hello, World!" << endl;

cout dipakai untuk menampilkan sesuatu ke layar. Tanda << berarti "kirim ke". "Hello, World!" adalah tulisan yang ditampilkan. endl memindahkan tampilan ke baris baru. Semua diakhiri titik koma ;.

7
return 0;

Menandakan program selesai berjalan dengan sukses, tanpa masalah.

8
}

Kurung kurawal penutup — tanda akhir dari fungsi main(). Program berakhir di sini.

Contoh 2 — Menampilkan Lebih dari Satu Baris

Kita bisa menulis cout lebih dari sekali untuk menampilkan beberapa baris tulisan.

Contoh 2 — duabaris.cpp🔒 ketik sendiri
#include <iostream>
using namespace std;
int main() {
cout << "Hello, World!" << endl;
cout << "Saya Dewi, senang belajar pemrograman C++" << endl;
return 0;
}
Tampilan di jendela Console setelah ditekan F11
Hello, World!
Saya Dewi, senang belajar pemrograman C++
Process exited after 0.01 seconds with return value 0
Press any key to continue . . .
✏️ Coba juga contoh ini. Ganti kalimat "Saya Dewi..." dengan namamu sendiri, lalu jalankan dengan F11.
07 · Bekal Tambahan

Hal Penting Lainnya

Beberapa hal kecil ini akan sering kamu temui dan berguna sejak sekarang.

Komentar Kode

Komentar adalah catatan di dalam kode yang tidak dijalankan oleh komputer. Gunanya untuk memberi keterangan supaya kode lebih mudah dipahami, oleh orang lain maupun oleh diri kita sendiri nanti.

komentar.cpp🔒 ketik sendiri
// Ini komentar satu baris, diawali dua garis miring
/* Ini komentar
yang bisa lebih dari satu baris */

Membuat Baris Baru — Dua Hal yang Berbeda

Pertanyaan yang sering muncul: "cara bikin baris baru di C++ gimana?" Ada dua konteks yang perlu dibedakan:

di editor

Baris kode baru

Sama seperti mengetik dokumen biasa — tekan tombol Enter di keyboard saat menulis kode di Dev-C++ untuk pindah ke baris berikutnya. Ini hanya soal rapi-rapi kode, tidak memengaruhi jalannya program.

di tampilan hasil

Baris baru pada output

Untuk membuat tulisan hasil program pindah ke baris baru di jendela Console, gunakan endl di dalam cout, seperti pada contoh Hello World di atas.

Selain endl, ada juga cara lain yaitu karakter "\n" yang ditulis di dalam tanda kutip. Untuk sekarang, cukup gunakan endl dulu supaya lebih mudah diingat.
