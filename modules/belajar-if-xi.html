Percabangan if, if-else, dan else if

Program yang kamu tulis selama ini berjalan lurus dari atas ke bawah. Sekarang program belajar mengambil keputusan seperti penjaga gerbang Taman Seru: boleh masuk atau belum, tarif berapa, dapat potongan atau tidak. Baca materinya, coba simulasinya, lalu uji pemahamanmu lewat kuis di bagian akhir.

if if-else else if if bersarang kondisi & operator

Tujuan Pembelajaran

Capaian Pembelajaran (Elemen Algoritma dan Pemrograman — Fase F): peserta didik mampu mengembangkan program terstruktur dan menuliskannya sebagai kode program sesuai kaidah bahasa pemrograman yang dipakai.

Tujuan Pembelajaran: melalui pengamatan, permainan, dan praktik menulis program C++ sederhana, peserta didik mampu (1) menjelaskan fungsi percabangan dan menulis program dengan if dan if-else memakai kondisi dari operator perbandingan, (2) menulis if bertingkat (else if) untuk memilih satu dari beberapa rentang nilai dan menjelaskan pentingnya urutan kondisi, (3) menulis if bersarang sederhana, (4) membedakan if dari switch-case serta memilih struktur yang tepat, dan (5) menggabungkan cin, operator, dan percabangan if dalam program yang dapat dikompilasi dan dijalankan.

01 · Konsep Dasar

Mengenal Percabangan

Dalam kehidupan sehari-hari kita terus mengambil keputusan: jika hujan, maka bawa payung. Program juga bisa begitu. Percabangan membuat program memilih tindakan berbeda tergantung kondisi yang sedang benar atau salah.

Bahasa sehari-hariBahasa C++
Jika total ≥ 50.000if (total >= 50000)
maka ...{ ... } (isi di dalam kurung kurawal)
jika tidak, maka ...else { ... }
jika tidak, tetapi jika ...else if (kondisi) { ... }

Kondisi ditulis dengan operator perbandingan. Hasilnya selalu benar atau salah.

OperatorArtinyaContoh (nilai = 80)Hasil
==sama dengannilai == 80benar
!=tidak sama dengannilai != 80salah
> <lebih besar / lebih kecilnilai > 90salah
>= <=lebih besar atau sama / lebih kecil atau samanilai >= 75benar
!

= dan == itu berbeda

Satu tanda sama dengan (=) berarti mengisi nilai. Dua tanda sama dengan (==) berarti membandingkan. Pada kondisi, selalu tulis if (nilai == 100), bukan if (nilai = 100).

02 · Satu Jalur

Percabangan if

if saja menjalankan isinya hanya bila kondisi benar. Bila kondisi salah, isinya dilewati dan program lanjut ke baris berikutnya.

Struktur dan Cara Kerja

BagianFungsi
if (kondisi)Kondisi yang diperiksa, ditulis di dalam kurung. Hasilnya benar atau salah.
{ ... }Isi keputusan. Hanya dijalankan bila kondisi benar.
Baris setelah }Berada di luar if, jadi selalu dijalankan.
!

Jangan beri titik koma setelah kondisi

if (kondisi); membuat isi if tidak lagi terkait dengan kondisinya. Pastikan juga setiap { punya } penutup.

Contoh Program: Diskon Belanja

Percobaan 1 — total belanja 60000 (kondisi benar)

Simulasi jendela Console setelah ditekan F11

Percobaan 2 — total belanja 30000 (kondisi salah)

Simulasi jendela Console setelah ditekan F11

Penjelasan Bagian Penting

9
cin >> total;

Nilai total belanja dibaca lebih dulu, supaya ada yang bisa diperiksa oleh kondisi.

11
if (total >= 50000) {

Kondisi ditulis di dalam kurung setelah kata if. Bacalah dengan suara: "jika total lebih besar atau sama dengan 50000, maka ...".

12–13
cout << "Selamat! ..." << endl;
}

Isi keputusan ditulis di dalam kurung kurawal { }. Baris ini hanya dijalankan kalau kondisinya benar.

14
cout << "Terima kasih ..." << endl;

Baris ini berada di luar if, jadi selalu tampil, baik total 60000 maupun 30000.

03 · Dua Jalur

Percabangan if-else

if-else menyediakan dua jalur: satu bila kondisi benar, satu lagi bila kondisi salah. Program pasti menjalankan salah satunya, tidak pernah keduanya.

Struktur dan Cara Kerja

BagianFungsi
if (kondisi) { ... }Jalur pertama, dijalankan bila kondisi benar.
else { ... }Jalur kedua ("jika tidak"), dijalankan bila kondisi salah. else tidak punya kondisi.
Hasil akhirTepat satu dari dua jalur yang dijalankan, tidak pernah keduanya.
★

Dua jalur, pasti satu yang jalan

Program selalu memilih salah satu: jalur if atau jalur else. Cocok untuk keputusan ya atau tidak, misalnya lulus atau belum lulus.

Contoh Program: Lulus atau Belum

Percobaan 1 — nilai 80

Simulasi jendela Console setelah ditekan F11

Percobaan 2 — nilai 60

Simulasi jendela Console setelah ditekan F11
11
if (nilai >= 75) {

Kalau nilai 75 atau lebih, jalur pertama dijalankan.

13
} else {

else berarti "jika tidak". Perhatikan bahwa else tidak punya kondisi; ia menangkap semua yang tidak lolos kondisi if.

✏️ Ketik program ini sendiri, lalu ubah syarat lulus menjadi 70 dan ganti pesannya sesuai kreativitasmu.

Contoh lain: Genap atau Ganjil

Operator % memberi sisa bagi. Angka genap bersisa 0 bila dibagi 2.

Percobaan — angka 7

Simulasi jendela Console setelah ditekan F11

Sisa bagi angka oleh 2 dihitung lebih dulu (angka % 2), lalu dibandingkan dengan 0 memakai ==. Untuk angka 7, sisanya 1, jadi kondisi salah dan jalur else yang jalan.

04 · Banyak Jalur

if Bertingkat: else if

Bila kemungkinannya lebih dari dua, kondisi disusun bertingkat seperti anak tangga memakai else if. Program memeriksa dari atas ke bawah dan berhenti pada kondisi pertama yang benar.

Struktur dan Cara Kerja

BagianFungsi
if (kondisi1)Anak tangga paling atas. Diperiksa lebih dulu.
else if (kondisi2)Anak tangga berikutnya. Punya kondisi dan hanya diperiksa bila kondisi di atasnya salah. Boleh ditulis berkali-kali.
elseLantai paling bawah, untuk semua yang tidak lolos kondisi di atas. Tidak punya kondisi dan boleh tidak ditulis.
★

Berhenti pada kondisi pertama yang benar

Program memeriksa dari atas ke bawah. Begitu ada kondisi yang benar, isinya dijalankan dan sisa anak tangga di bawahnya dilewati.

05 · Pengenalan Singkat

if Bersarang

if bersarang berarti if di dalam if. Keputusan kedua hanya diperiksa bila keputusan pertama lolos, seperti dua pintu berlapis: pintu 2 baru dijumpai setelah lolos pintu 1.

Struktur dan Cara Kerja

BagianFungsi
if (kondisiLuar)Pintu pertama. Diperiksa lebih dulu.
if (kondisiDalam)Pintu kedua, ditulis di dalam kurung kurawal pintu pertama. Hanya diperiksa bila pintu pertama lolos.
else masing-masingSetiap if boleh punya else sendiri untuk kasus ketika pintunya tidak lolos.
!

Pasangkan kurung kurawal dengan teliti

Setiap { harus punya } penutup. Rapikan indentasi (menjorok ke dalam) supaya jelas else milik if yang mana.

Contoh Program: Wahana (umur lalu tinggi)

06 · Memilih Struktur

if atau switch-case?

Kamu sudah mengenal dua cara mengambil keputusan. Keduanya punya keunggulan masing-masing.

🔀 if

Untuk rentang nilai

Contoh: nilai ≥ 75, umur < 12, tinggi ≥ 120. Bisa dipakai pada banyak tipe data dan kondisi yang bebas.

🎛️ switch-case

Untuk pilihan tetap

Contoh: menu 1–3, huruf A–D, angka 1–12 menjadi nama bulan. Hanya menerima int atau char.

Aspekifswitch-case
Cocok untukRentang nilaiPilihan tetap
Tipe dataBanyak tipe (bilangan bulat, desimal, string)Hanya int atau char
KondisiBebas, termasuk operator perbandingan dan logikaMencocokkan nilai yang sama persis
ContohNilai ujian menjadi lulus atau belumNomor menu menjadi nama makanan

Untuk pilihan tetap, keduanya menghasilkan keluaran yang sama, misalnya menu 1–3 bisa ditulis dengan switch-case atau dengan if dan else if. Tetapi untuk "nilai ≥ 75", switch-case tidak praktis karena harus menuliskan satu per satu angka 75, 76, 77, sampai 100.

★

Cara cepat memilih

Pilihan tetap, pakai switch-case. Rentang nilai, pakai if.

Hal Penting Lainnya

⚠️ = vs ==

Pembanding yang benar

= mengisi nilai, == membandingkan. Gunakan == di dalam kondisi.

⚠️ titik koma

Jangan beri ; setelah kondisi

if (nilai >= 75); membuat isi if tidak lagi terkait dengan kondisinya.

⚠️ kurung kurawal

Harus berpasangan

Setiap { punya } penutup. Kurung kurawal yang hilang adalah galat yang sangat umum.

⚠️ else if

Urutan dan kondisi

else if punya kondisi, else tidak. Mulai dari kondisi yang paling ketat.
