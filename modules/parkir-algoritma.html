Gerbang Algoritma
Biaya Parkir

Sebelum menulis satu baris kode pun, seorang programmer harus membedah masalah lebih dulu: apa yang masuk, apa yang harus keluar, dan aturan mana yang tidak boleh dilanggar.

SOAL — KEGIATAN KELOMPOK

Buatlah program yang dapat menghitung biaya parkir kendaraan.

Motor Rp2.000/jam
Mobil Rp4.000/jam
↓ Gulir untuk mulai analisis
Tahap 01 — Menganalisis Masalah

Input, Output & Batasan

Langkah pertama memecahkan masalah bukan menulis kode, tapi memahami bentuk masalahnya.

01 · INPUT

Masukan

  • Jenis kendaraan (motor / mobil)
  • Lama parkir dalam satuan jam
02 · OUTPUT

Keluaran

  • Jumlah biaya parkir yang harus dibayar
  • Pesan jika jenis kendaraan tidak dikenali
03 · BATASAN

Batasan Program

  • Jenis kendaraan hanya "motor" atau "mobil"
  • Lama parkir berupa bilangan bulat positif
  • Tarif tetap: motor Rp2.000/jam, mobil Rp4.000/jam
Tahap 02 — Mendesain Solusi

Narasi / Deskripsi Algoritma

Ditulis dengan bahasa manusia biasa, diurutkan langkah demi langkah supaya logikanya bisa diperiksa sebelum diterjemahkan ke kode.

Program Biaya Parkir
  1. Mulai Program
  2. Tampilkan permintaan untuk menginput jenis kendaraan
  3. Pengguna menginputkan jenis kendaraan
  4. Tampilkan permintaan untuk menginput lama parkir (jam)
  5. Pengguna menginputkan lama parkir
  6. Pengecekan apakah jenis kendaraan adalah "motor"
  7. Jika motor, hitung biaya = 2000 × jam, lalu tampilkan hasilnya
  8. Jika bukan motor, periksa apakah jenis kendaraan adalah "mobil"; jika ya, hitung biaya = 4000 × jam, lalu tampilkan hasilnya
  9. Jika bukan motor maupun mobil, tampilkan pesan "Jenis kendaraan tidak dikenali"
  10. Selesai
Tahap 02 — Mendesain Solusi

Pseudocode

Versi setengah-kode dari narasi di atas — cukup terstruktur untuk langsung diterjemahkan ke bahasa pemrograman apa pun.

Program Biaya Parkir

Mulai
   var string: jenis
   var int: jam, biaya

   Output ("Masukkan jenis kendaraan: ")
   Input (jenis)

   Output ("Masukkan lama parkir (jam): ")
   Input (jam)

   Jika jenis = "motor" maka
        biaya = 2000 * jam
        Output ("Biaya parkir: ", biaya)
   Selain itu
        Jika jenis = "mobil" maka
             biaya = 4000 * jam
             Output ("Biaya parkir: ", biaya)
        Selain itu
             Output ("Jenis kendaraan tidak dikenali")
Selesai

Tahap 03 — Mengimplementasikan Solusi

Menjadi Kode C++

Pseudocode di atas diterjemahkan langsung ke C++. Coba jalankan programnya dan lihat bagaimana tampilan terminalnya saat program benar-benar dieksekusi.

#include <iostream>
using namespace std;

int main() {
    string jenis;
    int jam, biaya;

    cout << "Masukkan jenis kendaraan: ";
    cin >> jenis;

    cout << "Masukkan lama parkir (jam): ";
    cin >> jam;

    if (jenis == "motor") {
        biaya = 2000 * jam;
        cout << "Biaya parkir: Rp" << biaya << endl;
    } else if (jenis == "mobil") {
        biaya = 4000 * jam;
        cout << "Biaya parkir: Rp" << biaya << endl;
    } else {
        cout << "Jenis kendaraan tidak dikenali" << endl;
    }

    return 0;
}
