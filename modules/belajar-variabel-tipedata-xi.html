Variabel dan Tipe Data

Setiap program butuh cara untuk menyimpan data — nama siswa, umur, nilai ujian. Di pertemuan ini kita belajar apa itu variabel, tipe data dasar di C++, aturan memberi nama variabel, serta cara mendeklarasikan dan mengisinya. Baca ringkasannya di bawah, lalu uji pemahamanmu lewat kuis di halaman berikutnya.

Variabel Tipe Data Aturan Penamaan Deklarasi & Inisialisasi

Tujuan Pembelajaran

Capaian Pembelajaran (Elemen Algoritma dan Pemrograman — Fase F): peserta didik mampu mengembangkan program terstruktur dengan strategi algoritmik yang tepat, menuliskannya menjadi kode program sesuai kaidah bahasa pemrograman yang dipakai, serta mengelola data dalam program menggunakan struktur yang sesuai dengan kebutuhan persoalan.

Tujuan Pembelajaran pertemuan ini: melalui pengamatan dan praktik menulis program C++ sederhana, peserta didik mampu (1) menjelaskan konsep variabel dan fungsi tipe data dalam menyimpan nilai, (2) mengidentifikasi dan memilih tipe data dasar (int, float/double, char, bool, string) yang sesuai kebutuhan, (3) menerapkan aturan penamaan variabel yang benar, dan (4) mempraktikkan deklarasi dan inisialisasi variabel dalam program C++ yang dapat dikompilasi tanpa galat.

01 · Pengenalan

Apa itu Variabel?

Variabel adalah nama untuk tempat penyimpanan di memori komputer, supaya sebuah nilai bisa disimpan dan dipakai lagi selama program berjalan.

Bayangkan variabel seperti kotak berlabel: isinya bisa dibaca atau diganti, tapi labelnya (nama variabel) tetap sama.

01

Nama Variabel

Sebutan unik untuk memanggilnya, misalnya umur.

02

Tipe Data

Menentukan jenis nilai yang boleh disimpan.

03

Nilai / Isi

Isi yang sedang tersimpan saat ini — bisa berubah selama program berjalan.

Tipe Data Dasar di C++

Setiap variabel wajib punya tipe data — ini memberi tahu komputer jenis nilai apa yang disimpan dan berapa memori yang disiapkan.

TipeUntuk MenyimpanContoh Deklarasi
shortBilangan bulat, jatah memori kecilshort jumlahKursi = 32;
intBilangan bulat, paling umum dipakaiint umur = 17;
longBilangan bulat, jatah memori besarlong jumlahPenduduk = 5000000;
floatBilangan desimal, presisi standarfloat tinggi = 165.5;
doubleBilangan desimal, presisi lebih tinggidouble luas = 12.75;
charSatu karakter (kutip satu)char kelas = 'A';
boolNilai benar/salahbool lulus = true;
stringRangkaian teks (kutip dua)string nama = "Wayan";

Ingat: char pakai kutip satu dan cuma satu karakter, string pakai kutip dua dan boleh banyak karakter. Untuk short/int/long, bedanya cuma soal jatah memori (kecil → besar). Untuk float vs double, bedanya soal ketelitian — kalau ragu, pakai double. Kalau memakai string, sertakan juga #include <string> di baris atas program.

02 · Aturan Penulisan

Aturan Penamaan Variabel

Nama variabel wajib mengikuti aturan berikut supaya program bisa dikompilasi.

1

Diawali huruf atau garis bawah

Boleh huruf (a-z, A-Z) atau _ — tidak boleh diawali angka.

2

Hanya huruf, angka, garis bawah

Tidak boleh ada spasi atau simbol lain seperti -, #, @.

3

Case-sensitive

nilai, Nilai, dan NILAI dianggap tiga variabel berbeda.

4

Tidak boleh memakai kata kunci C++

Kata seperti int, if, class, return sudah punya arti khusus.

5

Sebaiknya deskriptif

Bukan aturan wajib, tapi nilaiUjian lebih mudah dipahami daripada x.

Nama VariabelStatusAlasan
umurValidDiawali huruf, tanpa spasi/simbol
_tinggiValidDiawali garis bawah
2kelasTidak validDiawali angka
nilai ujianTidak validMengandung spasi
intTidak validKata kunci C++
03 · Praktik

Deklarasi dan Inisialisasi

Dua istilah yang sering tertukar:

langkah 1

Deklarasi

Membuat variabel — memberi tahu compiler akan ada kotak dengan nama & tipe tertentu. Contoh: int umur;

langkah 2

Inisialisasi

Mengisi variabel dengan nilai pertama kali. Contoh: umur = 17;

Keduanya bisa dilakukan sekaligus dalam satu baris — cara yang paling umum dipakai:

deklarasi.cpp🔒 ketik sendiri
#include <iostream>
using namespace std;
int main() {
int umur; // deklarasi: kotak "umur" dibuat, isi belum ditentukan
umur = 17; // inisialisasi: kotak "umur" diisi belakangan
int nilai = 90; // deklarasi + inisialisasi sekaligus
cout << "Saya umur " << umur << endl;
cout << "Nilai Informatika saya " << nilai << endl;
return 0;
}
Simulasi tampilan Console setelah ditekan F11
6
int umur;

Deklarasi — kotak bernama umur bertipe int dibuat, tapi isinya belum ditentukan (masih "kosong"/tidak pasti).

7
umur = 17;

Inisialisasi — kotak umur yang sudah dibuat di baris 6 diisi nilai 17 untuk pertama kalinya. Perhatikan: tanpa menulis tipe data lagi, karena sudah dideklarasikan sebelumnya.

9
int nilai = 90;

Deklarasi dan inisialisasi dilakukan sekaligus dalam satu baris — pola ini yang paling sering dipakai dalam praktik sehari-hari.

Beberapa variabel dengan tipe sama juga bisa dideklarasikan sekaligus, dipisah koma:

deklarasi-ganda.cpp🔒 ketik sendiri
int hari, bulan, tahun;
hari = 17; bulan = 8; tahun = 1945;
1
int hari, bulan, tahun;

Tiga variabel bertipe int dideklarasikan sekaligus dalam satu baris — nama-namanya dipisah dengan tanda koma ,, cukup tulis tipe datanya satu kali di depan.

2
hari = 17; bulan = 8; tahun = 1945;

Ketiga variabel yang baru dideklarasikan lalu diinisialisasi satu per satu — boleh ditulis dalam satu baris asalkan tiap pernyataan diakhiri titik koma ;.

✏️ Ketik kedua program di atas sendiri di Dev-C++, jangan copy-paste.

Deklarasi & Inisialisasi Semua Tipe Data

Sekarang mari lihat cara mendeklarasikan sekaligus menginisialisasi setiap tipe data dasar C++ dalam satu program:

semua-tipe-data.cpp🔒 ketik sendiri
#include <iostream>
#include <string>
using namespace std;
int main() {
short jumlahKursi = 32;
int umur = 17;
long jumlahPenduduk = 5000000;
float beratBadan = 58.5;
double tinggiBadan = 165.75;
char jenisKelamin = 'P';
bool sudahAbsen = true;
string namaLengkap = "Wayan Sari";
cout << "Jumlah Kursi: " << jumlahKursi << endl;
cout << "Umur: " << umur << endl;
cout << "Jumlah Penduduk: " << jumlahPenduduk << endl;
cout << "Berat Badan: " << beratBadan << endl;
cout << "Tinggi Badan: " << tinggiBadan << endl;
cout << "Jenis Kelamin: " << jenisKelamin << endl;
cout << "Sudah Absen: " << sudahAbsen << endl;
cout << "Nama Lengkap: " << namaLengkap << endl;
return 0;
}
Simulasi tampilan Console setelah ditekan F11
7
short jumlahKursi = 32;

Bilangan bulat dengan jatah memori kecil — cocok untuk angka yang pasti tidak akan pernah besar, seperti jumlah kursi di satu ruangan.

9
long jumlahPenduduk = 5000000;

Bilangan bulat dengan jatah memori besar — dipakai kalau angkanya diperkirakan terlalu besar untuk int.

10-11
float beratBadan = 58.5; double tinggiBadan = 165.75;

Keduanya untuk bilangan berkoma. Perhatikan titik . sebagai pemisah desimal (bukan koma). double lebih presisi daripada float.

12
char jenisKelamin = 'P';

char selalu memakai kutip satu '...' dan isinya hanya boleh 1 karakter.

13
bool sudahAbsen = true;

bool hanya boleh diisi true atau false — tanpa tanda kutip, karena ini kata kunci bawaan C++, bukan teks.

14
string namaLengkap = "Wayan Sari";

string memakai kutip dua "..." dan boleh berisi banyak karakter — beda dengan char yang hanya 1 karakter dan kutip satu.

04 · Bekal Tambahan

Hal Penting Lainnya

Kesalahan kecil yang paling sering terjadi saat baru belajar variabel dan tipe data.

⚠️ kutip keliru

char vs string

char selalu kutip satu, cuma 1 karakter — char g = 'A';. Kalau isinya lebih dari 1 karakter, seharusnya string.

⚠️ tipe tidak cocok

Nilai harus sesuai tipe

Jangan isi bool dengan angka sembarang, atau int dengan teks — program bisa gagal dikompilasi.

Beberapa kata kunci C++ yang tidak boleh dipakai sebagai nama variabel: int, short, long, float, double, char, bool, if, else, for, while, return, class.

05 · Praktik Gabungan

Praktik Gabungan: Data Siswa

Sekarang giliranmu menulis kode sendiri. Buatlah program C++ di Dev-C++ yang, ketika dijalankan (F11), menampilkan hasil persis seperti ini di Console:

Target tampilan Console yang harus dihasilkan programmu
Nama: Kadek
Umur: 16
Tinggi: 165.5
Jenis Kelamin: L
Suka Membaca: 1

Petunjuk

Perhatikan baik-baik setiap baris tampilan di atas untuk menentukan tipe data yang tepat:

  • Nama berupa rangkaian huruf — tipe data apa yang cocok?
  • Umur berupa bilangan bulat.
  • Tinggi berupa bilangan berkoma.
  • Jenis Kelamin hanya satu huruf — kutip satu atau kutip dua?
  • Suka Membaca tampil sebagai angka 1 — ingat-ingat tipe data apa yang tampil seperti itu di Console.
✏️ Tulis programmu sendiri di Dev-C++ (jangan lihat kunci jawaban dulu), jalankan dengan F11, lalu bandingkan hasilnya dengan target di atas.

🔑 Kunci Jawaban (Mode Guru)

datasiswa.cpp
#include <iostream>
#include <string>
using namespace std;
int main() {
string nama = "Kadek";
int umur = 16;
double tinggi = 165.5;
char jenisKelamin = 'L';
bool sukaMembaca = true;
cout << "Nama: " << nama << endl;
cout << "Umur: " << umur << endl;
cout << "Tinggi: " << tinggi << endl;
cout << "Jenis Kelamin: " << jenisKelamin << endl;
cout << "Suka Membaca: " << sukaMembaca << endl;
return 0;
}
Simulasi tampilan Console setelah ditekan F11
2
#include <string>

Wajib disertakan karena baris 7 memakai tipe string.

7-11
string nama = "Kadek"; ...

Lima variabel dideklarasikan sekaligus diisi, masing-masing dengan tipe yang sesuai jenis datanya — inilah kunci soal ini.

17
cout << sukaMembaca;

Nilai bool true tampil sebagai angka 1 di Console — inilah petunjuk kenapa "Suka Membaca" di target output berupa angka, bukan tulisan.
